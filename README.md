# SnapScale

SnapScale is a clean, responsive starting point for a visual-search experience. Enter a word, explore ideas, and build an inspiration wall.

## Features

- Branded landing page with a responsive layout
- Accessible search form with a labelled input
- Search suggestion chips
- Gallery section with a welcoming empty state
- Result-count placeholder and Clear control
- Responsive CSS Grid gallery layout
- Keyboard focus styles and reduced-motion support

## Run locally

1. Clone this repository.
2. Open `index.html` in your browser.
3. Explore the interface.

No build tools or dependencies are required.
